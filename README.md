# Running_snake

这是我的51单片机作业，我估计不会有人去看一个学生的作业，不过为了让项目完整一些，我还是写一下README
单片机： AT89C51 DIP40 双列直插

开发环境Proteus 8 Professional仿真，Keil uVision5程序编写
注意该项目从未经过实际测试，故不保证在实际单片机上的运行效果

代码思路：
确定出头的位置，通过头的位置倒推蛇的身体。
这里需要确定，蛇在8位数码管上的运行路径。思路大概是通过统一的index，构造两个可以对应起来的数组。
这两个数组分别对应位码和段码，这样一个路径就被确定下来了。如果需要更改路径，只需要改变Pos 和 Seg。
对于缓存与刷新，我用了一个数组储存每一个数位对应的显示状态。再通过1ms一刷新进行显示（视觉暂留）。
在每一次移动前都会扫描按键状态，来决定是否增长或缩短。
该代码在设计上决定了，每次移动只能增加一节，要增加两节就必须等下次。（可能有更好的解决办法，正在学习中）

局限性：
路径更改并不方便。许多地方还可以用常量进行替代。
消抖机制并不高明，而且由于scan（）的位置，一按下按键就会立刻变长，而不是等下次移动的时候变长。（可能下一版就改了）
有些地方的转换写的冗杂。_Seg Seg
变量名不够清晰，不能明确反应变量作用。

遇到的问题:
51中没有bool类型
unsigned char 引起的死循环
不能再for中定义变量
#define CONSTANT 10 不用'=' ';'
一开始我尝试用每个pos检索对应的位置是否有蛇的身体经过，过于麻烦，所以后来改成了通过蛇的身体反向得到每个pos的seg
